
# MOTION DIRECTOR

A dedicated ChatGPT project for generating high-quality, professional motion graphics video prompts optimized for **Google Flow**.

Inspired by premium SaaS launch films, Apple-style product presentations, Dribbble motion design, and Prompt Motion.

---

## Step 1 — Create a Dedicated ChatGPT Project

1. Open [ChatGPT](https://chatgpt.com/).
2. Click **New Project** in the sidebar.
3. Name the project:

   `Google Flow | Motion Studio`

4. Open the project settings.
5. Find **Project Instructions**.
6. Copy the **Google Flow Motion Director Master Instructions** and paste them into the Project Instructions field.
7. Save your changes.

### Master Instructions

Use the file:

`Google_Flow_Motion_Director_Master_Instructions.md`

Once configured, you won't need to paste the instructions every time you create a new chat inside the project.

---

## Step 2 — Describe Your Video Idea

Inside your ChatGPT project, start a new chat and explain what you want to create.

### Example Prompt

Create a 15-second premium motion graphics video for **ZYNEX Developments**.

**Concept:**
A futuristic software development agency advertisement showcasing advanced web development, modern UI, and business automation.

**Visual Style:**
Apple keynote meets high-end Dribbble motion design. Minimalistic, sophisticated, black and white with electric blue accents.

**Motion:**
Seamless shape morphing, kinetic typography, animated UI components, smooth camera movement, and satisfying transitions.

**Format:**
- Aspect Ratio: 16:9
- Duration: 15 seconds
- Platform: Google Flow

**Audio:**
Premium electronic soundtrack with synchronized UI sound effects. No narration.

**Expected Output:**
Generate the complete storyboard and detailed Google Flow prompts for each clip.

---

## Step 3 — Generate Videos in Google Flow

1. Visit [Google Flow](https://flow.google/).
2. Create a new project.
3. Select the appropriate video-generation model.
4. Choose the recommended generation mode.
5. Copy the first generated video prompt from ChatGPT.
6. Paste it into Google Flow.
7. Generate the video.
8. Repeat for the remaining clips.

For longer videos, generate individual clips and combine them into the final video.

Use reference frames when necessary to maintain visual continuity.

---

## Step 4 — Assemble and Polish

Use Google Flow's available editing features or professional editing software such as **DaVinci Resolve**.

Recommended finishing steps:

- Combine generated clips.
- Refine transition timing.
- Correct typography where necessary.
- Synchronize animation with music.
- Add professional sound effects.
- Check color consistency.
- Export the final video.

---

## Step 5 — Improve the Results

If a generated clip does not meet expectations:

1. Capture a screenshot or describe the problem.
2. Return to your ChatGPT project.
3. Explain what needs improvement.
4. Request an optimized replacement prompt.
5. Regenerate the clip in Google Flow.

### Example Refinement Request

The generated video has inconsistent UI shapes and awkward transitions.

Improve the prompt with:

- More precise geometric transformations.
- Smoother camera movement.
- Better object continuity.
- Professional motion easing.
- Cleaner typography.
- Consistent visual styling.

Keep the original creative direction.
